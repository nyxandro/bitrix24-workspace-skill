# Поля ответов и ловушки

Все команды отвечают конвертом `{ data, next, notes }`. Ниже — что лежит в `data` и на что
обращать внимание.

## Общее

- **Даты** — ISO 8601 со смещением (`2026-11-20T10:00:00+03:00`). Исключения:
  - у почты даты без смещения (`2026-11-10T10:00:00`) — Битрикс не сообщает зону;
  - у событий на весь день (`allDay: true`) — только дата `2026-11-20`;
  - если у события календаря не указана зона, время без смещения.
- **`truncated: true`** (или `descriptionTruncated`) — текст обрезан до 4 000 знаков;
  целиком — с `--full`. Скажи пользователю, что текст длинный, если это важно.
- **Люди** — `{ id, name }`. Имя `сотрудник N` значит, что Битрикс не отдал имя
  (уволенный или внешний сотрудник).
- **Ссылок на файлы и записи в ответах нет намеренно**: в них бывает ключ доступа. Файл
  скачивается командой `disk download`.
- В текстах значения вида `token=…`, `auth=…` заменены на `<скрыто>` (пометка в `notes`).

## status

- `sections` — раздел → `ok` или `нет права …`.
- `scopes.extra` — права вебхука, которые скиллу не нужны: их можно снять.
- `version.updateAvailable` — вышла новая версия скилла.

## chats

- `recent`: `dialogId`, `title`, `type` (`user` — личка, `chat`, `open`, `general`,
  `collab`, `copilot` и др.), `entity` — к чему привязан чат (`TASKS_TASK`, `SONET_GROUP`,
  `CALENDAR`), `unreadCount` — **настоящее** число непрочитанных, `markedUnread` — ручная
  пометка «непрочитано», `lastMessage` — начало последнего сообщения.
- `messages`/`search`: сообщения **по возрастанию времени**. У каждого `author`, `text`
  (разметка убрана, упоминания — `@Имя`), `system: true` у служебных событий (вход и выход,
  смена стадии) — не пересказывай их как речь людей. `files` — `{ fileId, name, size, type }`:
  скачать — `disk download <fileId> --out …`.
  - Без курсора — последние сообщения; `next` — для `--before` (более ранние).
  - С `--since` — все сообщения с даты, но не больше 500; если упёрлись — пометка и `next`.
  - С `--after` — более новые, `next` — для `--after`.
- `info`: участники — до 50, `membersTotal` — всего.

## notifications

`from` — кто (у системных `null`), `text`, `module` (`tasks`, `im`, `calendar`, …), `read`.

## projects

- `list`: `type` — `group`, `project`, `scrum`, `collab`; `isMember`; `dialogId` — чат группы
  для `chats messages`. Фильтр по типу Битрикс не умеет — скилл листает до 500 групп.
- `get`: `members` — до 50 с ролями (`владелец`, `модератор`, `участник`), `membersTotal`.

## tasks

- `list` по умолчанию — задачи, где пользователь ответственный, постановщик, соисполнитель
  или наблюдатель (`myRoles`). Это **не** все задачи компании, даже у администратора.
  `--page` работает только с одной `--role`.
- `status` по-русски: `новая`, `ждёт выполнения`, `выполняется`, `ждёт контроля`,
  `завершена`, `отложена`, `отклонена`.
- `get`: `dialogId` — чат задачи с обсуждением (`null` — чата нет); `linkedDialogs` — чаты,
  на которые есть ссылки в описании; `checklist` — пункты с `done` и `parentId` (пункт с
  `parentId: 0` — заголовок чек-листа).

## disk

- `storages` по умолчанию — мой диск, общий диск и диски моих групп; `--all` — всё видимое.
- `ls`/`search`: у файлов `size` в байтах; поиск ищет и по тексту документов, но не по файлам чатов.
- `download`: `path` — куда сохранён файл (имя без путей; совпадение — суффикс « (1)»),
  `size`. Предел по умолчанию 100 МБ.

## mail

- `list`: без текста письма; `seen`, `hasAttachments`. Текст — `mail get`.
- `get`: `text` — тело письма (HTML переведён в текст). Вложения писем недоступны в REST.
- `thread`: письма цепочки с `preview` — началом текста.

## calendar

`start`, `end`, `allDay`, `location`, `recurring` (повторяющееся — отдельная запись на каждую
дату), `isMeeting`, `myResponse`, `attendees` — `{ id, name, response }`
(`принял`, `отклонил`, `не ответил`, `организатор`). `event` добавляет `description`.

## meetings

Только встречи, где пользователь участник. `list`: `callId`, `topic`, `participants`.
`get`: `topic`, `agenda`, `agreements`, `actionItems`, `takeaways`, `summary` — по частям;
`transcript` — только с `--transcript` (до 40 000 знаков, целиком — `--full`).

## feed

`list`: начало текста (до 1 000 знаков), `comments` — число комментариев; целиком —
`feed post <id>` с комментариями.

## kb

`search` — `snippet` с выдержкой; курсора у поиска нет — уточняй запрос. `doc` — `text` в
Markdown.

## org

`me`: `departments` с `path` (путь в структуре) и `managers`, `colleagues` до 50,
`colleaguesTotal`. `department`: `managers`, `employees` до 50, `employeesTotal`.

## worktime

`status`: `идёт`, `закрыт`, `на паузе`, `не закрыт вовремя`. `records`: записи по дням с
`durationSeconds` и `breakSeconds`, `totalSeconds` — сумма.
