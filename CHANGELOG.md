# Changelog

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [0.1.1] — 2026-11-14

### Исправлено
- Шапка `SKILL.md`: описание взято в кавычки. Из-за двоеточия в тексте строгие разборщики
  YAML (страница файла на GitHub, часть установщиков) не читали шапку скилла.

## [0.1.0] — 2026-11-13

Первая версия: чтение рабочего Битрикс24 через входящий вебхук, только чтение.

### Добавлено
- `status` — проверка подключения, доступность разделов, лишние права, новая версия скилла.
- Чаты: `chats recent|counters|find|info|messages|search`, `notifications`.
- Задачи и проекты: `tasks list|get` (по всем ролям владельца вебхука), `projects list|get`.
- Диск: `disk storages|ls|search|file|download`.
- Почта: `mail boxes|list|get|thread`.
- Календарь и встречи: `calendar upcoming|events|event`, `meetings list|get` (ИИ-итоги).
- Лента и база знаний: `feed list|post`, `kb list|search|tree|doc`.
- Структура и время: `users find|get`, `org me|find|department`, `worktime status|records`.
- Безопасность: список разрешённых методов только для чтения с проверкой формы имени метода;
  ключи вебхука и ссылок на скачивание не выводятся; финальная проверка вывода.
- Установщик `install.sh`, архив `bitrix24-workspace.skill`, инструкция агенту `SKILL.md`.
- `status` предупреждает, если файл с адресом вебхука открыт другим пользователям машины.
- `feed post` сообщает, сколько комментариев всего (`commentsTotal`), `mail thread` и
  `disk storages` — что показано не всё.
- Автопроверка на каждый push: тесты, типы, линтер, свежесть собранного файла и архива,
  совпадение номера версии во всех файлах.

### Исправлено по итогам ревью перед выпуском
- Текст сообщений: одиночные `[i]`, `[b]`, `[s]`, `[u]`, `[p]` больше не вырезаются — раньше
  `a[i] = b[i]` превращалось в `a = b`. Оформление убирается только парой тегов.
- Пустой ответ Битрикса вместо объекта даёт понятную ошибку, а не пустую карточку:
  `projects get`, `disk file`, `disk download` — `APP_B24_NOT_FOUND`; `worktime status`,
  `status` — `APP_B24_UNEXPECTED_RESPONSE`.
- `tasks get`: номер чата `0` означает «чата нет», а не `chat0`.
- Скачивание: адрес переадресации проверяется до запроса по нему — только ссылка на
  скачивание того же портала.
- Файл с адресом вебхука создаётся сразу закрытым (`umask 077`) — и установщиком, и командой
  из инструкции.
- `install.sh --help` работает и при запуске через `curl … | bash`.
