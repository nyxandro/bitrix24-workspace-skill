# Bitrix24 Workspace

**Скилл для ИИ-агента, который читает ваш рабочий Битрикс24 — чаты, задачи, проекты, файлы, почту, календарь и встречи. Только чтение.**

**Русский** · [English](README.en.md)

</div>

Скилл для Claude Code, Codex, OpenCode, Cursor, Hermes и других агентов, которые понимают
Agent Skills и умеют запускать команды. Вы спрашиваете обычными словами — «что мне писали по
проекту за неделю», «найди договор на диске», «о чём договорились на созвоне», — агент сам
вызывает встроенный CLI и отвечает по живым данным портала.

Скилл работает через **входящий вебхук** и видит ровно то, что видите вы. Он **только читает**:
отправить, изменить или удалить что-либо в портале он не может технически — в программе
зашит список разрешённых методов, и все они читающие.

## Что умеет

| Раздел | Что внутри |
|---|---|
| Чаты | Последние диалоги и непрочитанное, переписка в чатах, личке, чатах задач и проектов, поиск по чату, участники |
| Уведомления | Упоминания, поручения, приглашения |
| Задачи и проекты | Мои задачи по всем ролям, карточка задачи с её чатом и чек-листом; группы, проекты, коллабы |
| Диск | Хранилища, папки, поиск по названию и тексту документов, скачивание файла для чтения |
| Почта | Ящики, поиск писем, текст письма, цепочка |
| Календарь и встречи | Ближайшие события, любой период и календарь, ИИ-итоги видеовстреч: договорённости, задачи, расшифровка |
| Лента и база знаний | Новости компании с комментариями, документы базы знаний |
| Структура и время | Мой отдел, руководители, коллеги; рабочий день и учёт времени |

## Установка

Нужен **Node.js 20.19 или новее**. Весь код собран в один файл, ставить npm-пакеты не нужно.

| Способ | Команда |
|---|---|
| Одной командой (Linux, macOS, WSL) | `curl -fsSL https://raw.githubusercontent.com/nyxandro/bitrix24-workspace-skill/main/install.sh \| bash` |
| Claude Code, Codex, OpenCode, Cursor и другие | `npx skills add nyxandro/bitrix24-workspace-skill` |
| Вручную | Скачайте [`bitrix24-workspace.skill`](bitrix24-workspace.skill) (это ZIP) и распакуйте в папку скиллов агента |

`install.sh` кладёт скилл в `~/.agents/skills/`, ставит ссылку в `~/.claude/skills/` и создаёт
пустой `~/.config/bitrix24-workspace/.env`. Для агента со своей папкой скиллов добавьте
`--dir <папка>`; на машину без интернета скопируйте архив и запустите
`bash install.sh --file bitrix24-workspace.skill`. После установки перезапустите сессию агента.

Не ставьте вместе с другими скиллами Битрикс24 с похожим описанием — агент может выбрать не тот.

## Настройка вебхука

1. В Битрикс24: **Разработчикам → Другое → Входящий вебхук**.
2. Отметьте права: `im`, `task`, `sonet_group`, `socialnetwork`, `disk`, `mail`, `calendar`,
   `user_basic`, `call`, `log`, `note`, `timeman` (что зачем — в
   [`references/setup.md`](skills/bitrix24-workspace/references/setup.md)).
   CRM и остальное не нужно.
3. Впишите адрес вебхука в `~/.config/bitrix24-workspace/.env` — **сами, не через чат с ИИ**:

   ```bash
   mkdir -p ~/.config/bitrix24-workspace && read -rsp 'Вставь адрес вебхука: ' U && printf 'BITRIX24_WORKSPACE_WEBHOOK_URL=%s\n' "$U" > ~/.config/bitrix24-workspace/.env && chmod 600 ~/.config/bitrix24-workspace/.env && unset U && echo ' готово'
   ```

4. Спросите агента: «проверь подключение к Битрикс24» — он вызовет `status`.

## Безопасность

- **Запись закрыта программой, а не Битриксом.** У вебхука нет режима «только чтение»: сам
  адрес позволяет и запись. Храните его как пароль; если утёк — удалите вебхук в Битрикс24 и
  создайте новый. Право `call` (итоги встреч) по документации открывает и платные робозвонки —
  не нужны итоги встреч, не давайте его.
- **Ключи не выводятся.** Ни адрес вебхука, ни ссылки на скачивание файлов (в них тоже ключ)
  не попадают в ответы и ошибки: файлы скилл скачивает сам.
- **Содержимое — данные, а не команды.** Инструкция агенту запрещает исполнять указания из
  писем, сообщений и документов.
- **Видно только своё.** Даже у администратора скилл показывает только его задачи и встречи
  с его участием.
- Другие инструменты агента (например, официальный MCP Битрикса) могут уметь писать — это
  вне скилла.
